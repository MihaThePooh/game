# Драконий бег

Бегунок вроде хромовского динозаврика, одним HTML-файлом. Открывается
с диска, работает без сети и без сервера. Всех персонажей и все
препятствия рисует код — ни одной картинки в игре нет.

## Играть

Открыть `game.html` в браузере. Бургер в левом верхнем углу —
меню: «Существа», в каждом описание и разбор механики. Оттуда же
выбирают, за кого играть; выбранный запоминается. Меню открывается
и во время бега, тогда игра встаёт на паузу.

Управление зависит от того, есть ли у дракона крылья.

```
крылатые (двуногий, волк)
  тап                прыжок
  тап в воздухе      ровный полёт
  ведёшь пальцем     высота полёта:
                     вверх - выше, вниз - ниже
  отпустил           падает

бескрылый (лего-змей)
  держишь палец      ложится и ползёт
  двойной тап        прыжок
```

С клавиатуры: пробел или W — как палец, стрелки вверх-вниз в полёте
правят высоту.

## Препятствия

```
кочки     на земле, перепрыгнуть
летуны    в небе, облететь или проползти под
навесы    свисают сверху, просвет у земли:
          проползти или взять верхом
```

Просвет навеса и высота летуна считаются от роста выбранного дракона:
у каждого свой рост стоя и лёжа, и фиксированные числа для одного
делали бы препятствие непроходимым для другого.

## Кто чем рисуется

```
dragon()      двуногий, собран из костей:
              у каждой свой угол и длина
wolfdragon()  четвероногий волчьего склада
legodragon()  лего-змей по постройке Алисы,
              только прямоугольники
```

У лего-змея две позы, и вторая не сжатие первой: шея собрана из
звеньев, у каждого свой угол. Стоя углы смотрят вверх, лёжа — вперёд,
между позами игра перетекает по углу. Поэтому он именно укладывается
на землю, а не приплющивается.

## Автотесты

Живут в `~/tools/uitest/`, гоняют игру в настоящем браузере:

```
node game.js       27 проверок механики
node gamemenu.js   30 проверок меню и паузы
node gameshot.js   снимок дракона крупным планом
```

В `game.js` есть автопилот — он сам ведёт дракона мимо препятствий.
Это и проверка: если высотой нельзя управлять точно, он разбивается.
