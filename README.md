# Драконий бег

Бегунок вроде хромовского динозаврика, одним HTML-файлом. Открывается
с диска, работает без сети и без сервера.

Особенность в другом: героя, кочку и летуна можно заменить **детским
рисунком**. Фотографируешь рисунок, скрипт вырезает фон и делает
спрайт — и он бежит, подпрыгивает и хлопает крыльями. Пока картинка
не подставлена, всех персонажей рисует код.

## Играть

Открыть `game.html` в браузере. Пробел или касание — прыжок.
Адрес с `?code` показывает всех, кого рисует код.

## Рисунок в спрайт

```
python3 sprite.py фото.jpg спрайт.png
```

Из зависимостей — только `ffmpeg`, и тот работает голым декодером:
отдаёт сырые RGB-байты, чтобы не тащить Pillow. Всё остальное
считает стандартная библиотека.

Главная сложность — вырезать бумагу. Постоянный порог по яркости
бесполезен: на снимке с телефона белый лист выходит серым, и порог,
подобранный на одном фото, разваливается на другом. Работает
нормализация по локальному фону — каждый пиксель делится на среднюю
яркость вокруг себя, после чего бумага везде равна единице.

Ещё две вещи, найденные на живых рисунках:

- тонкий контур при уменьшении рассыпается на сотни кусочков, поэтому
  отбрасываются только пятна, упирающиеся в край кадра: пружины
  блокнота, тень, край стола;
- контур от руки негерметичен и заливка вытекает наружу — линии
  сначала утолщаются, потом худеют обратно, и силуэт замыкается.

Посмотреть результат на шахматке, чтобы увидеть прозрачность:

```
python3 preview.py спрайт.png лист.png
```
